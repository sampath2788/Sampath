# Research data and submission note

**Study:** Data-Quality-Aware Knowledge-Based AI-Driven Claims Analytics for Explainable Coverage Validation

**Author:** Sampath Kumar Puvvada (Sysintel Inc.)

The published results in this working project are **synthetic simulation outputs**, not claims-adjudication outcomes from CMS or an insurer. The synthetic train/validation/test data are deterministically regenerated by `claims_benchmark.py` using the documented fixed seeds. No private employer data, protected health information or identifiable member information are included.

## Generate all results

```bash
python -m pip install -r requirements.txt
python -m pytest -q test_claims_benchmark.py
python claims_benchmark.py --out results --members 2200 --target-risk 0.03
```

The command generates the seed-level metrics and reproduces `results/table1.csv`, `results/table2.csv`, and both figures (`results/figure1.png`, `results/figure2.png`, with vector PDFs). Note the statistical limitations: the quality-aware method underperforms a strong coverage-matched selective-ML comparator; synthetic coverage labels are not independently adjudicated. The simulated corruption fraction is a scenario parameter, not an estimated insurer-data defect prevalence.
